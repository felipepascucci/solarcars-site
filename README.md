# Solar Cars — Site Institucional

Site estático de uma loja fictícia de carros movidos a energia solar, com páginas de início, sobre e contato. Foi um dos meus primeiros projetos web, feito em 2023 para praticar HTML e CSS.

## Páginas

- **Início** (`index.html`) — apresentação da marca e de como funciona a compra
- **Sobre** (`Sobre.html`)
- **Contato** (`Contato.html`)

## Tecnologias

- HTML5 e CSS3
- jQuery
- Layout base gerado com o construtor visual Nicepage (`nicepage.css` / `nicepage.js`) e adaptado manualmente

## Como executar

Não precisa de instalação: basta abrir o `index.html` no navegador.
